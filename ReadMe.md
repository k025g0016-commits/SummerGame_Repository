ゲーム概要
・盾を投擲して敵を攻撃したり、敵の攻撃をガードしながらステージの最後にいるボスを倒すことを目指すアクションゲームです

操作方法
・左右移動
　左右ArrowKey
　A/DKey

・ジャンプ
　SPACEKey

・攻撃
　ZKey

・ガード
　左SHIFT

・ポーズ
　ESC

・ポーズメニューの選択・決定
　上下ArrowKey,SPACEKey

敵の種類
・剣敵
　近距離にプレイヤーがいると前進しながら攻撃します

・弓敵
　一定範囲内にプレイヤーがいると矢を放ちます

・盾敵
　正面方向の攻撃を防ぎます。一定範囲内にプレイヤーがいると穴や崖を無視して突進攻撃を行います

・ボス
　正面攻撃を防ぎます。プレイヤーが離れていると突進攻撃や遠距離攻撃を行います。近距離にプレイヤーがいると前進しながら近接攻撃を行います。プレイヤーが背後にいるとその場で回転攻撃を行います

・注意点
　本ゲームはコントローラー非対応です
